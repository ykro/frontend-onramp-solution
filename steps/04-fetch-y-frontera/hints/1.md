# Pista 1. Tres problemas distintos

- `fetch` considera exitosa cualquier respuesta que llegue, incluso un `404`. La respuesta trae una propiedad que dice si el código está entre 200 y 299.
- Cada vez que cambia `termino`, el efecto arranca una búsqueda nueva, pero nadie le avisa a la anterior que ya no importa. React te da un lugar para hacer eso, la función que devuelve el efecto.
- `BuscadorRapido.tsx` solo necesita el límite de resultados. Ese valor existe en dos archivos; uno de ellos además guarda una llave secreta.

Lee [Sincronizar con efectos](https://es.react.dev/learn/synchronizing-with-effects) y abre [la pista 2](2.md) si ya ubicaste cada problema.
