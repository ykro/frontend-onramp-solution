# Pista 2. Orden de las revisiones

1. Quita los espacios de los extremos. Si no queda nada, la respuesta es `null`.
2. Convierte el texto limpio a número.
3. Si el resultado no es un número finito, o no es mayor que cero, la respuesta es `null`.
4. Si pasó todo, devuelve el número.

Cada `return null` temprano hace que, en las líneas siguientes, TypeScript ya sepa que el valor es válido.

Si quieres ver la forma, abre [la pista 3](3.md).
