# Pista 1. Qué busca el test

Los tests de este paso no miran clases ni `id`. Buscan lo mismo que un lector de pantalla, un rol y un nombre. Si `getByRole("button", { name: /confirmar reserva/i })` falla, es porque nada en la página tiene rol de botón con ese nombre. Un `<div>` con `onClick` no lo tiene.

Revisa la tabla de [roles implícitos de HTML](https://developer.mozilla.org/es/docs/Web/Accessibility/ARIA/Roles) para ver qué etiqueta da cada rol. Para el CSS, lee el comentario de arriba de `tarjeta-reserva.css`.

Si ya sabes qué etiqueta va en cada lugar, abre [la pista 2](2.md).
