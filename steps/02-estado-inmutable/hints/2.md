# Pista 2. Arreglos nuevos y keys que no cambian

- Para agregar sin mutar, crea un arreglo nuevo con lo que ya había más el elemento nuevo. El operador spread (`...`) copia los elementos de un arreglo dentro de otro.
- Pásale a `setGastos` una función que reciba el estado anterior y devuelva el arreglo nuevo. Así no dependes de una variable que podría estar desactualizada.
- Para el total, quítalo del estado y calcúlalo en cada render a partir de `visibles`.
- Para la `key`, usa un dato que identifique al gasto sin importar su posición. Cada gasto ya trae uno.

Si quieres ver la forma, abre [la pista 3](3.md).
