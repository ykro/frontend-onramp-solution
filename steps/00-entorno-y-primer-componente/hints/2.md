# Pista 2. Las tres herramientas

- Para el título, mete la prop dentro del texto del `<h2>` con llaves.
- Para el contador, cambia la variable `let` por `useState`, que se importa desde `"react"`. El botón debe llamar a la función que te devuelve `useState` en lugar de reasignar la variable.
- Para la lista, `temas.map(...)` convierte cada texto en un `<li>`. React pide una prop `key` única en cada elemento de una lista; el mismo texto del tema sirve aquí. Lee [Renderizado de listas](https://es.react.dev/learn/rendering-lists).

Si quieres ver la forma general, abre [la pista 3](3.md).
