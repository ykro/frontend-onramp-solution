# Pista 1. Qué ve React y qué no

El título y la lista ya reciben los datos correctos; la línea **Props recibidas** lo demuestra. El problema es que el JSX no los usa. Lo que va entre llaves dentro del JSX se evalúa como JavaScript.

El contador es otra historia. React dibuja el componente una vez y solo lo vuelve a dibujar cuando algo le avisa. Una variable con `let` cambia en memoria, pero React no se entera. Lee [El estado, la memoria de un componente](https://es.react.dev/learn/state-a-components-memory).

Si `npm install` o `npm run dev` fallan, revisa la tabla de errores comunes en el [README principal](../../../README.md#errores-comunes-al-preparar-el-entorno).

Si ya entiendes por qué el contador no cambia, abre [la pista 2](2.md).
